# 📸 MarryMoments

A modern wedding photo sharing platform built for Indian photographers.

## 🎯 Overview

PhotoShare Pro allows photographers to upload wedding photos instantly and share them with guests via QR codes and access codes. Guests can view and download photos in real-time.

## ✨ Key Features

- 📱 Mobile-first photo upload with camera integration
- 🔢 Secure access codes for each wedding event  
- 📱 QR code generation for instant guest access
- 💬 WhatsApp sharing integration
- ☁️ Cloud storage with automatic image optimization
- 📊 Real-time analytics and engagement tracking

## 🛠️ Tech Stack

- **Frontend:** Next.js 15, Tailwind CSS, Shadcn UI
- **Backend:** Node.js, Express.js, MongoDB
- **Storage:** Cloudinary CDN
- **Deployment:** Render.com

## 🚀 Live Demo

- [MarryMoments](https://marrymoments-frontend.onrender.com)

## 📱 Usage

1. **Photographer** creates event and gets access code
2. **Upload photos** during the wedding ceremony
3. **Share QR code** with guests for instant access
4. **Guests** view and download photos immediately

## 🇮🇳 Made for India

Designed specifically for Indian wedding photographers with mobile-optimized interface and local sharing preferences.
